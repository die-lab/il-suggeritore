# Il Suggeritore

App per imparare le battute di un copione teatrale: prova con la battuta nascosta dietro un sipario, ripasso veloce con salto rapido alla scena, lettura del copione. Funziona nel browser e si installa sul telefono come app (con la sua icona).

È una pagina statica: `index.html` contiene tutta l'app, `manifest.webmanifest` e `icons/` danno nome e icona quando la aggiungi alla schermata Home, `sw.js` la fa funzionare anche senza rete.

I progressi restano salvati nel browser del telefono. Per spostarli da un'altra versione: *Cambia copione → Sposta i progressi*.
